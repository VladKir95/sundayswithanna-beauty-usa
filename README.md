# Sundays with Anna (beauty)

Setup on a new computer:
1. Install Node.js LTS (https://nodejs.org) and Git (https://git-scm.com).
2. `npm install`
3. `npm run dev` -> http://localhost:4321 (shop: /shop/)
4. Build check: `npm run build`

Photo tools need Python: see tools/README.md. Project guide for Claude: CLAUDE.md.
